# 🪙 BlockForge

BlockForge is a minimal blockchain implementation built for educational purposes.

---

## 🚀 Features

- Block structure with SHA-256 hashing
- Proof-of-Work mining
- Transaction pool
- Mining rewards
- Chain validation logic
